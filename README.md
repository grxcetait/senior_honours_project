# Data Science Techniques Applied to Cosmology
**Senior Honours Project** · University of St Andrews

> Mapping the neutral hydrogen distribution in the Universe using Gaussian Process Regression and machine learning to separate cosmological signals from astrophysical foregrounds — applied to data from the MeerKAT radio telescope.

---

## Background

By observing the redshifted 21cm emission line from neutral hydrogen (HI), we can construct 3D maps of its distribution and infer the underlying dark matter density field. This structure encodes rich cosmological information about the history and evolution of the Universe.

However, the cosmological signal is buried beneath astrophysical foregrounds that are orders of magnitude brighter. This project develops and applies signal separation techniques — centred on **Gaussian Process Regression (GPR)** — to remove these foregrounds and recover the HI signal, using a combination of simulated and real MeerKAT observations.

## Getting Started

### Prerequisites

- Python 3.9+
- Jupyter Notebook or JupyterLab

### Installation

```bash
# Clone the repository
git clone https://github.com/grxcetait/senior_honours_project.git
cd senior_honours_project

# Create a virtual environment (recommended)
python -m venv venv
source venv/bin/activate        # macOS/Linux
# venv\Scripts\activate         # Windows

# Install dependencies
pip install -r requirements.txt
```

### Running the Notebooks

```bash
jupyter notebook
```

Then navigate to `notebooks/exploratory/` to run the raw working notebooks, or `notebooks/clean/` for the polished, reproducible versions.

> **Note:** The clean notebooks are self-contained and designed to be run top-to-bottom without modification. The exploratory notebooks reflect the research process and may require some manual setup.
