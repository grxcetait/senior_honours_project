# Foreground Removal in HI Intensity Mapping: Comparing Principla Component Analysis and Gaussian Process Regression
**Senior Honours Project** · University of Edinburgh

> Mapping the neutral hydrogen (HI) distribution in the Universe using Principal Component Analysis (PCA) Gaussian Process Regression (GPR) to separate cosmological signals from astrophysical foregrounds, applied to data from the MeerKAT radio telescope.

## Background

By observing the redshifted 21cm emission line from neutral hydrogen (HI), we can construct 3D maps of its distribution and infer the underlying dark matter density field. This structure encodes rich cosmological information about the history and evolution of the Universe.

However, the cosmological signal is buried beneath astrophysical foregrounds that are orders of magnitude brighter. This project develops and applies signal separation techniques, PCA and GPR, to remove these foregrounds and recover the HI signal, using a combination of simulated and real MeerKAT observations.

## Getting Started

### Prerequisites

- Python 3.9+
- Jupyter Notebook or JupyterLab
-  `git` (required to install GitHub-only dependencies)

### Installation

```bash
# Clone the repository
git clone https://github.com/grxcetait/senior_honours_project.git
cd senior_honours_project

# Create a virtual environment (recommended)
python -m venv venv
source venv/bin/activate        # macOS/Linux
# venv\Scripts\activate         # Windows

# Install dependencies
pip install -r requirements.txt
```

> **Note:** Some dependencies (`meer21cm`, `katbeam`, `pygdsm`) are installed
> directly from GitHub rather than PyPI. The command above handles this
> automatically, but requires `git` to be installed on your system.

### Running the Notebooks

```bash
jupyter notebook
```

Then navigate to `notebooks/exploratory/` to run the raw working notebooks, or `notebooks/clean/` for the polished, reproducible versions.

> **Note:** The clean notebooks are self-contained and designed to be run top-to-bottom without modification. The exploratory notebooks reflect the research process and may require some manual setup.

## Key Results

This work compares Principal Component Analysis (PCA) and Gaussian Process Regression (GPR) for foreground removal methods in simulated HI intensity mapping. 

PCA successfully recovered the HI power spectrum after removing three principal components, with the residual signal lying within the 1-sigma uncertainties of the true HI signal across the full k range after applying a minimum threshold of k-parallel = 0.3 M/pc. 

GPR modelled the HI signal with an exponential kernel and the foreground with a spectral-index-modified RBF kernel, with hyperparameters constrained via MCMC sampling, recovering the HI signal well at high k but providing an incomplete foreground removal at low k. 

While PCA outperforms GPR for this idealised simulation by leveraging the statistical structure in the data, GPR's ability to propagate uncertainties and incorporate physical priors may be a valuable asset for next-gerenation surveys with MeerKAT.
