\begin{abstract}
Here we present ground-based transit photometry on WASP-135b using the Physics Innovations Robotic Astronomical Telescope Explorer (PIRATE). The observations were reduced using standard CCD procedures, including bias subtraction and flat field correction, which were then used in differential photometry. Airmass correction was performed on reduced data to determine the true magnitudes of WASP-135b. By performing colour analysis and dust extinction, we determine the host star has a stellar classification of K2. By modelling the light curve using the \texttt{batman} package we extract key system parameters to report WASP-135b has radius $1.15(3)\text{ $R_\text{{Jup}}$}$, mass $1.65(4)\text{ $M_\text{{Jup}}$}$, transit depth $0.0217(9)$, and transit duration $0.066(2)\text{ days}$.
%\big(\frac{R_p}{R_\star}\big)^2 
\end{abstract}
